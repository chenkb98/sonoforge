# synthesis


## `timebase`

生成半开采样时钟，时长换算到帧数后四舍五入。限制总帧数为一千万，防止错误的秒/毫秒参数导致巨大分配。

## `sine`

生成单声道正弦音，频率必须低于 Nyquist。振幅与相位是显式实验参数；相位单位为弧度。

## `square`

生成基础 square 振荡器。只限制基频，未对高次谐波做带限处理，适用于可复现测试样本而非高保真合成。

## `sawtooth`

生成基础 sawtooth 振荡器。只限制基频，未对高次谐波做带限处理，适用于可复现测试样本而非高保真合成。

## `triangle`

生成基础 triangle 振荡器。只限制基频，未对高次谐波做带限处理，适用于可复现测试样本而非高保真合成。

## `noise`

使用局部随机数生成器生成均匀白噪声，相同参数得到相同数组。不读取或改变 NumPy 全局随机状态。

## `chirp`

通过积分线性频率得到相位，支持向上或向下扫频。起止频率都需低于 Nyquist；零时长输出空音频。
