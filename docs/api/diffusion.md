# diffusion


## `linear_schedule`

构造线性 beta 噪声方差调度，所有值严格位于 (0, 1)，并限制最大步数。单步时使用起始方差。

## `cosine_schedule`

离散化余弦累计信号比例，将最后一步 beta 截断到 0.999，避免完全为零的累计 alpha 引起除零。

## `validate_schedule`

校验 beta 向量类型、有限性和范围，并拒绝累计 alpha 小到无法稳定反演的调度。返回副本以隔离调用者修改。

## `forward_noise`

按累计信号比例 alpha 混合干净信号和显式噪声。噪声由调用者提供，因此前向过程可以严格复现并独立验证。

## `predict_clean`

给定噪声预测反演前向过程，返回未削波的干净信号估计。拒绝过小 alpha，避免把数值误差无限放大。

## `ddim_step`

执行 eta=0 的确定性 DDIM 更新。前一时刻 alpha 必须不小于当前值，最后一步可设为 1 以得到干净信号估计。

## `initialize_model`

初始化带归一化时间条件的仿射噪声预测器。这是可训练的教学基线，不能替代预训练音频生成大模型；窗口宽度最多 256。

## `predict_noise`

将短音频窗口与归一化时间拼接后预测噪声。批量结果应与逐窗口预测一致，返回二维批次矩阵。

## `training_loss`

计算非空批次上的噪声预测均方误差。它衡量此训练目标，不可用于宣称真实音频感知质量。

## `train_denoiser`

在参数副本上执行全批次梯度下降，保留原模型以支持失败回滚与比较。测试只验证小型合成任务上的损失下降，不代表已训练语音大模型。

## `checkpoint_encode`

检查模型字段与形状后写入版本化 NPZ，字段仅含 version、weights、bias，不保存 pickle 对象或任意 Python 状态。

## `checkpoint_decode`

读取时校验压缩包成员数量、解压尺寸、精确字段集合和版本类型，再检查参数形状与有限性。未知字段、错误版本和对象数组均不能进入模型。

## `sample`

从局部种子噪声执行确定性 DDIM 反向采样，输出一个模型窗口并做最终削波。未训练模型的输出仅用于流程测试，不宣称具有语义或音质。

## `training_pairs`

对每个干净窗口抽取时间步与高斯噪声，返回噪声样本、目标噪声和归一化时间。可逐行反演验证所有前向训练配对。
