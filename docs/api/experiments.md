# experiments


## `config`

配置采用固定字段集合，包含生成器、采样率、时长、频率、振幅、种子与采样步数。未知字段立即报错，防止拼写错误默默改变实验。

## `parse_prompt`

提供明确的小型符号提示语法，例如 `sine 440`、`chirp 220 880` 和 `noise`。这不是自然语言理解，也不将任意文本伪装为语义音频生成。

## `render`

同一接口连接确定性合成器与显式提供的可训练扩散基线。扩散按短窗口生成，不保证跨窗口连续性；相关限制在演示中明确体现。

## `sweep`

以种子优先顺序构造参数笛卡尔积，每次最多一千个组合。各配置独立复制，修改一个结果不会影响其他实验。

## `audio_digest`

对规范 PCM16 WAV 的完整字节计算 SHA-256，将采样率和声道数纳入内容身份。量化后相同的音频会得到相同摘要。
