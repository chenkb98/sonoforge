# experiments


## `config`

配置采用固定字段集合，包含生成器、采样率、时长、频率、振幅、种子与采样步数。未知字段立即报错，防止拼写错误默默改变实验。

## `parse_prompt`

提供明确的小型符号提示语法，例如 `sine 440`、`chirp 220 880` 和 `noise`。这不是自然语言理解，也不将任意文本伪装为语义音频生成。

## `render`

同一接口连接确定性合成器与显式提供的可训练扩散基线。扩散按短窗口生成，不保证跨窗口连续性；相关限制在演示中明确体现。

## `sweep`

以种子优先顺序构造参数笛卡尔积，每次最多一千个组合。各配置独立复制，修改一个结果不会影响其他实验。

## `audio_digest`

对规范 PCM16 WAV 的完整字节计算 SHA-256，将采样率和声道数纳入内容身份。量化后相同的音频会得到相同摘要。

## `manifest`

清单保存精确配置、帧数、声道数、内容摘要以及峰值/RMS 诊断。生成结果形状必须与配置一致，不接受挂错时长或声道的产物。

## `manifest_encode`

序列化前完整验证清单契约，使用排序字段和严格有限 JSON。未知字段、缺失字段、布尔伪整数及不可能的 RMS/峰值组合会被拒绝。

## `manifest_decode`

严格解析清单 JSON，包括重复键和 NaN/Infinity 拒绝策略。读取与再次写入保持规范化字节结果一致。

## `generate_run`

把多份配置连接为可运行的实验批次，每个产物与自己的清单绑定。先校验全部配置，再开始生成，避免尾部参数错误导致部分计算结果混杂。
